# 商品销售战略报告 PDF 版式规范

本文件只规定「商品销售战略报告.md」的分享版 PDF。内容仍以 Markdown 为唯一母稿；PDF 不另写、不删改结论，也不暴露内部方法、Agent 指令或方法来源。

## 版式目标

PDF 面向品牌方、渠道方和合作伙伴阅读，应让人先看懂结论与决策，再查阅分析过程。它是一份正式商业报告，不是 Markdown 的逐行打印版，也不是商详长图。

视觉基准：

- A4 竖版、暖白底；
- 克制的砖红作为唯一主强调色；
- 有封面、阅读导航、章节分页、页眉和页码；
- 中文正文以苹方或兼容的无衬线字体呈现；
- 表格使用横线分隔，不使用密集全框线；
- 重点判断用浅暖灰引用卡，不滥用彩色底块；
- 宽表格自动缩小字号和单元格留白，但不得裁切、重叠或横向溢出。

## 文档结构

渲染器应按以下顺序组织页面：

1. 封面：报告标题、副标题、分析对象、市场、渠道、本轮目标、日期和可选署名；
2. 阅读导航：只列读者可见的一级阶段和开头的结论摘要；
3. 结论摘要：直接进入主要决策；
4. 正文章节：每个一级阶段从新页开始；
5. 最终决策卡；
6. 主要资料来源；
7. 作者与工具签名。

Markdown 中位于第一条 H1 后的连续引用块视作封面元信息，不在正文重复。引用块中的 `> # 钩子` 只是传播主张，不得被误判为一级章节或加入阅读导航。

## 字体与节奏

- 正文约 10.5—11.5pt，行距约 1.8—2.0；
- H1 约 21—22pt，并带砖红色下划线；
- H2 约 15—16pt，使用左侧色条；
- H3 约 12—13.5pt，使用更细的左侧色条；
- 正文页左右留白约 22—25mm；
- 段前段后保持稳定，不通过连续空行制造版面；
- 标题与紧随其后的正文或表格尽量同页；正文避免单行悬挂。

## 表格

表格是商品战略报告的主要信息载体，必须优先保证可读性：

- 表头顶部使用主色横线，底部使用深灰细线；
- 正文行只保留浅灰横向分隔线；
- 表头跨页重复；完整数据行尽量不跨页；
- 1—4 列使用标准字号；5 列及以上自动进入紧凑模式；
- 不能为了塞进一页把所有表格统一缩成极小字号；
- 长表允许自然跨页，不能截图后缩放塞入 PDF。

## 来源附录

- 「主要资料来源」属于附录，不沿用正文一级章节的粗体砖红强调；
- 附录主标题改用较小的中性灰标题，分组标题不加色块和左侧色条；
- 每条网络来源同时显示来源名称和完整 URL；来源名称与 URL 均应可点击；
- URL 使用较小的中性灰字号，允许自然换行，但不得裁切；
- 本地材料只显示材料名称，不把本地绝对路径印在对外 PDF 中。

## 封面与署名

- 默认副标题为「中国市场新品销售策略」；
- 封面默认只显示生成日期，用户指定报告署名时再使用 `--author`；
- 报告末尾固定保留作者签名区：`本报告由 eCommerce-helper skill 工具协助生成`、`Skill 设计与维护：嘉然 Jiaran`、`交流和建议可联系作者：嘉然 Jiaran（+v: evadebot）`、`个人网站：https://c.aoao.ai`；
- Skill 作者署名、使用者通过 `--author` 指定的报告署名和工具生成说明是三种不同身份：报告署名显示在封面，Skill 作者署名显示在报告末尾；
- 对外 PDF 不出现外部方法来源、内部工作过程或本地绝对路径。

## 渲染命令

```bash
python3 scripts/md_to_pdf.py \
  "01-商品销售战略/商品销售战略报告.md" \
  "01-商品销售战略/商品销售战略报告.pdf" \
  --date YYYY-MM-DD
```

可选参数：

- `--title`：覆盖封面标题；
- `--subtitle`：覆盖封面副标题；
- `--author`：添加报告署名；
- `--engine chrome|weasyprint|auto`：指定渲染引擎；
- `--chrome /path/to/Chrome`：指定 Chrome／Chromium；
- `--html-output`：保留用于排查的中间 HTML；
- `--keep-html`：保留临时 HTML。

默认优先使用 Chrome，找不到时再尝试 WeasyPrint。Chrome 可通过 macOS、Linux 和 Windows 的常见安装位置自动发现，也可以用 `ECOMMERCE_HELPER_CHROME` 指定。

## 交付前目视检查

PDF 生成成功不代表验收通过。必须：

1. 用 `pdfinfo` 确认 A4、页数和文件非空；
2. 用 `pdftoppm` 把全部页面渲染为图片；
3. 先看全页缩略图，检查空白页、章节节奏和异常分页；
4. 再按原尺寸检查封面、阅读导航、最宽表格、引用卡、最终决策卡、来源页与作者签名；
5. 用 `pypdf` 或 `pdfplumber` 抽取文本，抽查标题、主推 SKU、建议零售价和核心主张；
6. 检查所有网络来源既显示 URL 又保留 PDF 点击链接；
7. 若发现封面多出一页、引用钩子被当成章节、宽表裁切、附录过度强调、标题孤立、签名遗漏或页码缺失，修正样式后重新渲染全部页面。
