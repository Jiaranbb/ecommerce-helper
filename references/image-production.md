# 商详与社媒图片制作

## 输入门槛

只在用户确认最终商详文字后执行。开始前收集：

- 正面商品图、包装细节、背标／中文标签；
- Logo 或字标；
- 用户认可的视觉参考（如有）；
- 最终逐屏文字包；

若只做文字阶段，不要求用户提前准备图片、品牌规范或参考页面。

## 通用图片规格

商品详情主体图不按成交平台分叉，统一制作成：

- 每个商详模块一张独立竖图；
- 3:4 比例；
- 最终统一为 1080 × 1440 PNG；
- 第 1 页为视觉母版，其余页面沿用同一品牌系统；
- 便于不同电商页面按页加载、替换、删减和重排。

除非用户明确要求：

- 不拼接成长图；
- 不在一张图里塞多个完整页面；
- 不让页面因文字多少改变画布尺寸。

如果用户另外要求平台首图、搜索缩略图、直播卡片或广告素材，把它们视为通用商详之外的衍生资产，另定尺寸；不得借此改变主体分屏图。

## 共用视觉母版

第 1 张商详首屏通过后，记录并复用于社媒素材：

- 品牌关键词和避免出现的气质；
- 主色、辅助色、背景材质和留白比例；
- Logo 位置、最小安全区和不可变形规则；
- 标题、正文、标签的字体层级；
- 商品图真实性要求和允许变化的摄影角度；
- 装饰元素、卡片、线条和图标语言。

社媒图不是商详页的裁切版。它们共享品牌系统和商品真实性，但按渠道任务重新构图。

## 制作步骤

1. 使用当前 Agent 已配置并获得用户授权的图像生成／编辑工具；环境提供 `$imagegen` 时完整遵循其输入、保存和检查规则。没有图像工具时只交付逐图 Prompt 与制作清单。
2. 用当前环境的图像查看能力检查每张本地素材（Codex 可使用 `view_image`），明确：编辑目标、商品真实性参考、Logo 参考、标签事实参考、风格参考。
3. 先做第 1 页视觉母版。固定：画布、配色、Logo 位置、标题区、正文字号、页边距、图片窗口、装饰元素和商品真实性。
4. 母版通过后，每个页面单独调用一次图像生成；不得用一张批量拼图代替多张独立资产。
5. 每页 prompt 只提供该页文字和一个画面任务，并重复系列不变项。
6. 将生成结果复制到项目目录，以两位数页码命名。
7. 运行尺寸统一脚本，再逐页目视检查。

## 通用 Prompt 骨架

```text
Use case: ads-marketing
Asset type: [商品] 商品详情分屏系列，第 [N] 页，共 [Total] 页
Canvas: 3:4，最终 1080 × 1440；一张完整独立页面。

Input images:
- 图 1：视觉母版，只参考品牌系统、字体层级、页边距与质感。
- 图 2：商品真实性参考，保持瓶型／包装／标签／颜色。
- 图 3：Logo 或标签事实参考（按需）。

Series invariants:
- 与母版相同的画布比例、背景、配色、Logo 位置、标题区和安全边距；
- 商品包装不变形，不改标签，不创造新 SKU；
- 所有文字必须逐字清晰，只出现指定文案；
- 不添加二维码、条码、认证章、奖章、五星、促销贴纸或乱码；
- 内容在单页内一次看完，不拼成长图。

Page task: [这一页只完成的说服任务]
Visual: [一个主要画面]
Text (verbatim):
「……」
```

## 页面设计规则

- 每页只有一个主标题和一个主视觉；
- 单页文字不能依赖上一页才能读懂；
- 信息页用卡片、双栏或矩阵，但同组卡片必须等宽等高；
- 商品主视觉保持原包装识别，浓淡、颜色和瓶盖不能漂移；
- 对比页中的两个商品等高、等比例、同基线；
- 价格页的商品名、规格、¥ 数字和活动条件必须逐字核对；
- FAQ 使用 2 × 2 或单列等高卡片，避免小字号；
- 页面间可以改变摄影题材，但不能改变品牌系统。

## 尺寸统一

生成模型可能返回接近目标比例而非精确尺寸。统一使用：

```bash
python scripts/normalize_images.py \
  --input-dir "03-分屏商详" \
  --output-dir "03-分屏商详-1080x1440" \
  --width 1080 --height 1440
```

脚本按中心裁切后缩放，不拉伸；输入和输出目录必须不同。输出目录已存在同名 PNG 时默认停止，只有用户确认覆盖后才传 `--overwrite`。若主体贴边，先重新生成或人工确认，不能依赖裁切救图。

## QA 清单

逐页检查：

- 精确为 1080 × 1440，比例为 3:4；
- 页码与文字包顺序一致；
- Logo、品牌名、SKU、规格、价格、年份、奖项和数字无误；
- 中文无错字、乱码、缺字或错误标点；
- 商品瓶型、包装、液体／材质颜色与参考一致；
- 所有内容在安全区，单页可完整看完；
- 卡片等宽等高，对比商品等高等比例；
- 没有未经要求新增的徽章、条码、评分、促销词或假证明。

任何关键文字或商品识别错误都必须重做该页；不要用「仅供示意」交付商业成品。

## 社媒配图

社媒图片只在对应渠道文字定稿后制作。先读取 `social-media-pack.md` 的配图清单，再按渠道逐组生成：

| 渠道 | 默认规格 | 生产重点 |
|---|---|---|
| 小红书 | 1080 × 1440，3:4 | 封面一句话抓注意；轮播每页一个观点，组内品牌系统一致 |
| 私域群 | 1080 × 1440 或 1080 × 1080 | 一屏说清商品、使用或 Offer，避免广告感过重 |
| 朋友圈 | 1080 × 1080 优先 | 与短文互补，商品和场景优先，不把正文全文放图上 |
| 公众号 | 按发布端当前规格 | 头图负责主题，文内图负责解释、节奏或证明 |
| 短视频 | 1080 × 1920，9:16 | 输出封面、关键帧或分镜参考，不冒充完整视频成片 |

同一渠道的一组轮播必须等尺寸；不同渠道允许分别导出。每张图的 prompt 写明渠道、角度编号、序号、用途、逐字文案、视觉母版和商品真实性参考。

除用户明确要求，不在图片里生成二维码、购买链接、用户头像、聊天截图、五星评价或平台 UI；这类内容容易失真，应由后期排版或真实素材提供。
