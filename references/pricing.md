# SKU、Offer 与人民币价格

## 一、先定商品角色

不要从用户暂时拥有的组合、库存或旧链接反推商品必须怎么卖。分别判断每个候选 SKU 是否能够独立成立，再设计：

- 主推／获客款：最能创造需求和品牌记忆；
- 日常／复购款：用途稳定、补货自然；
- 入门／试用款：降低首次尝试门槛；
- 组合：解决一个明确的共同购买任务；
- 礼赠：具有场合理由、包装、说明卡、手提袋和送达体验。

高端商品不自动等于礼品。两种商品被放在一起也不自动等于组合价值；检查消耗速度、共同使用频率、销售单元与补货方式。

## 二、建立三类锚点

### 市场锚点

比较同品类、同规格、同用途和同渠道的实际到手价。跨国价格只能作为成本和定位线索，不能直接等同中国售价。

### 价值锚点

核心卖点、可见结果、专业资格、稀缺性、服务和包装能支撑什么价格带？价格表达应回到顾客结果，而不是只讲海外原价或品牌年份。

### 成本底线

纳入采购、进口、税费、入仓、包装、拣配、支付、平台、投流、破损、售后和商家承担的运费。

```text
商品毛利率＝（售价－含税到仓成本）÷售价

贡献利润＝实际成交价－卖家折扣－完整变动成本

最低售价＝（固定变动成本＋目标贡献利润）÷（1－按售价计提的费率）
```

成本缺失时仍须给出建议价，同时倒推「这个价格允许的完整变动成本上限」和价格失效条件。

## 三、价格架构

至少输出：

| 项目 | 必答内容 |
|---|---|
| 日常标价 | 品牌位置与心理门槛 |
| 首发／新客价 | 优惠金额、期限或验证目的 |
| 组合／多件 | 是否需要，怎样避免拆买倒挂 |
| 包邮 | 是否成立，成本由谁承担 |
| 单次使用价值 | 每次、每份、每天或每单位成本 |
| 成本闸门 | 目标毛利或贡献利润下的上限 |
| 失效条件 | 什么成本、竞价或转化结果会推翻建议 |

不要虚构原价、稀缺、销量、包邮能力或数学意义上的「最优价格」。

## 四、上市测试

设计可逆的小范围测试：日常价、首发价、必要时一个更高价；比较贡献利润而不只比较订单量。写出：

- 测试渠道、SKU 与时间；
- 内容角度与价格变量；
- 加购、支付转化、实际成交价、贡献利润、退货、破损和复购；
- 保留、调整和撤回条件。

价格页面要同时回答「多少钱」「为什么值」「为什么现在试」以及「如果不合适如何降低风险」。
